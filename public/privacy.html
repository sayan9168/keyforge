Privacy policy

Your passwords stay with you.

Effective date: September 8, 2026 · Published by Sayanox Private Limited

KeyForge Ultra is a browser-based password security workspace. Its design goal is that passwords never leave your device. This page explains exactly what the app does and does not collect, in plain language.

The short version: No account. No analytics. No cookies. No tracking. No server-side password storage. Generation, strength analysis, and comparison run entirely in your browser. The only external request is an optional, explicitly approved breach lookup.

1. What runs on your device

  • Password generation uses the browser’s Web Crypto random number generator.
  • Strength analysis runs locally using the zxcvbn-ts engine in a Web Worker — nothing is sent to a server for analysis.
  • Optional in-tab history is held in page memory only and is off until you enable it.
  • Fonts, word lists, and application code are hosted with the app; no third-party assets are loaded from other domains.

2. The only external request (optional breach check)

The checker can ask Have I Been Pwned whether a password has appeared in public breach data. This happens only after you tick an explicit consent box and click the check button. The request sends only the first five characters of the password’s SHA-1 hash (a k-anonymity prefix), never the password or full hash, and no cookies, cache, or referrer header are attached. Because the lookup travels over the internet, the service and network operators can still see your IP address and that prefix. You can cancel the request at any time.

3. What we do not collect

  • No passwords, usernames, or secrets are written to any server by the app itself.
  • No analytics or telemetry scripts are included.
  • No advertising or third-party trackers.
  • No account system, and no profile is created for you.
  • No cookies are set by the application.

The static hosting provider may keep ordinary access logs (such as IP address, user agent, and requested URL) as part of operating the site, as virtually all web hosts do.

4. Your control

  • Clear session removes revealed passwords and resets the interface.
  • History is disabled by default; disabling it or reloading clears the in-tab list.
  • Revealed passwords are hidden when the tab goes to the background.

JavaScript cannot guarantee that secrets are forensically erased from device memory, the clipboard, or downloaded files. KeyForge is a generation and education tool, not a password vault.

5. Children’s privacy

KeyForge is a general-purpose security tool and does not knowingly collect any personal information from anyone, including children under 13. If you believe personal information has reached us in error, contact us using the details below.
